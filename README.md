# StudentResearch

## Current Semester: Summer 2026

Summer 2026 is a coordinated CHI build, test, and documentation phase centered on LG-038 as an evolving blended research environment. The current cohort is working toward a basic operational room system by the end of July, with August reserved for experimentation, iteration, and extension across physical, virtual, semantic, and media workstreams.

The current summer effort includes triptych/scenic structure development, projection testing, immersive and distributed audio deployment, Unity-based digital twin work, semantic and AI/LLM experimentation, documentation/media production, and related creative/research contributions.

## Repository Description

This repository supports CHI student research proposals, current-semester operations planning, and governance documentation across multiple CHI meta-projects. It functions both as a student-facing coordination space for active semesters and as a continuing record of proposals, planning materials, and repository organization logic.

## Repository Structure

- [Proposals](Proposals): student proposal intake and semester proposal records.
- [Operations](Operations): current semester execution documents at the folder root, with prior or obsolete operations materials kept in `Operations/Archive`.
- [Governance](Governance): persistent framework and policy documentation for repository organization.
- [assets](assets): shared media and related support materials.
- [minutes-reports](minutes-reports): meeting records, reports, and related documentation.

## Proposal and Operations Lifecycle

- [Proposals/Current](Proposals/Current): active or recently active proposal cycles.
- [Proposals/Archive](Proposals/Archive): historical proposal cycles retained for continuity.
- [Operations](Operations): current live semester operations documents.
- [Operations/Archive](Operations/Archive): prior-semester or obsolete operations materials.
