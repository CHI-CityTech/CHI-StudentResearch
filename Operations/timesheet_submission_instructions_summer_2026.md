# CHI Summer 2026 Timesheet Submission Instructions

Use this guide to submit and manage weekly timesheets for Summer 2026.

## Where Timesheets Are Tracked

- Repository for issue creation: `CHI-StudentResearch`
- Project board for time reporting: [TimeSheets Project (CHI-CityTech Project 67)](https://github.com/orgs/CHI-CityTech/projects/67)

## Weekly Submission Workflow

1. Create your weekly issue in `CHI-StudentResearch`.
2. Open the `Timesheet (Summer 2026 TimeSheets)` issue template.
3. Complete all required sections:
   - week covered;
   - daily/weekly hours;
   - deliverables;
   - links to work.
4. Submit the issue.
5. Confirm the issue appears in the TimeSheets project board.
6. Keep the issue updated during the week as work progresses.
7. Move the issue card to `Submitted` when your week is complete.

## Board Status Guidance

- `Timesheet in Progress`: active weekly logging.
- `Submitted`: student has completed weekly entry and submitted for review.
- `Approved` (or `Archived`, depending on board setup): mentor/supervisor has verified entry.

## Required Practice

- Submit one timesheet issue per student per week.
- Use the timesheet template for all entries.
- Include links/evidence for work completed each week.
- Keep hours and deliverables current, not retroactive at end of term.

## Notes

- If the issue does not auto-appear in Project 67, add it to the project manually.
- If template options do not appear in the project page, create from the repository issue chooser instead.
