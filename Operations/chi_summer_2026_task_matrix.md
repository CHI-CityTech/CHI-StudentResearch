# CHI Summer 2026 Task Matrix
## Initial and Developing Tasks by Participant

**Purpose:** This companion document translates the conceptual Summer 2026 Statement of Work into a more operational task list. It is not yet a final engineering schedule. Instead, it identifies first tasks for each participant based on currently available proposals, statements of work, and project direction, and then sketches a broader developing task inventory for the summer.

## 1. Use of This Document

This document should be treated as a working task matrix rather than a locked production schedule. The first tasks listed for each participant are intended to be concrete enough to guide the launch phase. Later tasks are intentionally more provisional and may change as equipment is confirmed, systems are tested, and dependencies become clearer.

Tasks should be refined after launch-week inventory confirmation, room mapping, and first-priority technical assessments.

## 2. Shared Launch-Phase Tasks for the Entire Cohort

Before individual workstreams separate, the following tasks apply broadly across the cohort:

1. Attend the launch meeting in LG-038 on Monday, July 13, 2026 at 10:00 a.m.

## 5. Provisional Task Philosophy

This document begins with specificity where current roles and materials support it. It becomes intentionally more ambiguous further out because the summer work depends on launch-week confirmation, room access, physical equipment state, and evolving subsystem dependencies.

The goal is not to pretend that the full production schedule is already known. The goal is to ensure that each participant has a meaningful starting point and that the project begins generating a shared, evolving task structure from the first week onward.
